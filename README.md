# Investment Analyzer v11

Investment Analyzer v11 es una plataforma profesional de análisis de inversiones diseñada para producir decisiones transparentes, explicables y respaldadas por evidencia.

## Objetivos

- Arquitectura modular
- Múltiples proveedores de datos
- Valuación por DCF
- Análisis fundamental
- Análisis técnico
- Riesgo financiero
- Macroeconomía
- Smart Money
- Backtesting
- Explainability Engine
- Confidence Engine
- Reportes HTML, PDF, DOCX y JSON

## Características

- Security Master
- Symbol Resolver
- Data Orchestrator
- Provider Manager
- SQLite
- Cache Inteligente
- Decision Engine
- Portfolio Engine
- Dashboard
- Plugins
